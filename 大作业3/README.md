# 大气污染防治法律法规与标准知识图谱系统

本系统是课程大作业的扩展版本地 Web 系统，围绕“大气污染防治法律法规与标准知识图谱构建”课题实现法规、标准、污染物、行业场景、监管措施、监测方法、排放环节、区域和发布机构之间的关联检索。

## 打开方式

直接双击 `index.html`，或在浏览器中打开：

```text
E:\workplace\大作业\index.html
```

## 功能

- 数据规模扩展为 263 个实体节点、679 条关系边、67 个法规标准类节点。
- 多页面系统：总览看板、图谱探索、法规标准库、污染物库、行业场景、路径查询、数据质量、团队分工。
- 图谱探索支持关键词检索、实体类型筛选、关系类型筛选、1/2 跳邻域查看、重点链路高亮、节点详情。
- 法规标准库支持按关键词、文件类型和年份筛选。
- 污染物库和行业场景库支持按对象查看相关标准、污染物、行业和监管措施。
- 路径查询支持任意两个实体之间的最短路径展示，并可跳转回图谱查看。
- 数据质量页展示来源覆盖、年份分布和后续维护清单。
- 支持重置视图、暂停/恢复布局、缩放、导出 JSON 和 CSV 数据。

## 文件结构

```text
index.html              系统入口
assets/styles.css       页面样式
assets/graph-data.js    知识图谱数据
assets/expanded-data.js 扩展数据集

reports/                报告输出目录
screenshots/            系统截图目录
```
